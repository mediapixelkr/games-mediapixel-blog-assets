# JSON Prompts & Ideogram v2 (or v1)/v4 ComfyUI Integration Assets

This directory contains assets, prompts, workflows, and images for the article about integrating JSON prompts with Ideogram in ComfyUI.

## Directory Structure

- **[prompts/](prompts/)**: JSON files, text files, and structured prompts utilized for generating images.
  - [01-futuristic-sports-car-blueprint.json](prompts/01-futuristic-sports-car-blueprint.json): A professional game art blueprint sheet of a sleek futuristic sports car.
  - [02-fantasy-reward-box.json](prompts/02-fantasy-reward-box.json): A stylized fantasy game asset concept of an ornate wooden reward box.
  - [03-action-adventure-heroine.json](prompts/03-action-adventure-heroine.json): An original action-adventure game heroine inside an ancient stone ruin.
  - [04-explorer-character-turnaround.json](prompts/04-explorer-character-turnaround.json): A professional game character turnaround sheet showing an original female explorer.
- **[images/](images/)**: Sample images generated using the workflows and prompts.
- **[workflows/](workflows/)**: ComfyUI workflow JSON files that can be imported directly into ComfyUI.
